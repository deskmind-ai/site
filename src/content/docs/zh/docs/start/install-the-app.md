得心 Mac 应用把整个循环装进一个原生应用：输入目标，确认它可以使用哪些应用，它就替你操作，并显示每一步做了什么、为什么这么做。

:::caution[暂未公开]
Mac 应用还没有发布。发布后，安装包会放在 [github.com/deskmind-ai/app/releases](https://github.com/deskmind-ai/app/releases)。在那之前，你可以自己运行模型，见[快速上手](/zh/docs/start/quickstart/)。
:::

## 系统要求

- Apple 芯片的 Mac。
- macOS 15 或更高版本。
- 模型所需的磁盘空间：规划模型（0.8B + 4B）约 5.3 GB；加上可选的视觉模型，另需约 3.3 GB。可用空间不足约 7.5 GB 时，应用会在下载前提醒你。
- 内存：两个规划模型连同运行时，运行时约占 7 GB。内存小于 12 GB 的 Mac 上，应用会提示模型可能很慢或加载失败，建议先退出其他应用。

## 安装

1. 从 [Releases 页面](https://github.com/deskmind-ai/app/releases)下载 DMG。
2. 打开 DMG，把 **DeskMind** 拖进「应用程序」。
3. 从「应用程序」里打开 DeskMind。

发布版用 Developer ID 签名，并经过 Apple 公证。

## 两个应用，一套权限

得心由两个应用组成：

- **DeskMind**：你看到的窗口。它本身不需要任何隐私权限。
- **DeskMind Hands**：随应用一起安装的后台助手，负责观察和操作。所以 macOS 会把权限记在 **DeskMind Hands** 名下，而不是 DeskMind。

首页有一张「准备工作」卡片，会带你一项项完成。必需的项目都就绪后，它会收成一行。

| 项目 | 用途 | 是否必需 |
|---|---|---|
| 后台助手 | 启动 DeskMind Hands | 必需 |
| 本地模型 | 下载并启动规划模型 | 必需 |
| 辅助功能 | 读取窗口里的按钮和文字，并替你点击、输入 | 必需 |
| 屏幕录制 | 看见屏幕上的内容，判断任务进行到哪一步 | 必需 |
| 自动化 | 让访达和文本编辑在后台保存、移动文件 | 可选 |
| 视觉模型 | 在没有辅助功能树的应用里定位控件 | 可选 |

授权「辅助功能」和「屏幕录制」时，应用会打开系统设置里对应的页面，并在旁边显示 DeskMind Hands 的图标。把图标拖进列表，再打开 **DeskMind Hands** 旁边的开关。开关打开后，这一行会自动确认，助手会重新启动让授权生效，不会关掉你的窗口。

「自动化」权限在助手第一次操控某个应用时，由系统弹窗授予。

## 首次运行：下载模型

第一次使用时，「本地模型」一行会提示下载约 5.3 GB（0.8B 和 4B 两个规划模型）。

- 应用从 Hugging Face 下载发布版模型（DeskMind Brain G18b），每个文件都固定到具体版本，使用前逐个按 SHA-256 校验。
- 如果 Hugging Face 下载失败或太慢（某个文件开始后 30 秒内平均不到约 200 KB/s），会自动改从 ModelScope 下载同样的文件，用同一组 SHA-256 校验。在中国大陆，通常走的就是这条路。
- 下载可以暂停、继续，进度会保存。
- 下载完成后，应用把模型载入内存，通常需要 30 秒左右。

视觉模型（约 3.3 GB）只在你主动点下载时才下载，入口在它自己那一行；只有任务需要时才会载入。

:::note[哪些地方会联网]
应用自己发出的网络请求只有模型下载。规划模型和视觉模型的服务只监听 `127.0.0.1`，离线运行。屏幕、截图、运行记录和录屏都留在你的 Mac 上。得心替你操作的应用（比如 Safari）会照常联网。
:::

## 确认能用

应用没有单独的自检。首页的「试试示例」提供一组示例任务，可以起到同样的作用：

- **6 个冒烟任务**，在模拟桌面上运行：只在内存里的虚拟窗口上操作，用来确认应用、助手和本地运行时都接通了，不碰任何真实的东西。
- **真实沙箱任务**，在访达和文本编辑里运行（新建文件夹、把文件移进文件夹、按类型归档文件、中文精确写入并保存）。每次都在新的沙箱文件夹里进行，不碰你的文件，并由评分器检查结果。

如果出了问题，见[常见问题排查](/zh/docs/how-to/troubleshooting/)。

## 第一个任务

在首页输入目标。开始之前，得心会列出要用到的应用，请你确认。文件操作只限于你附加的文件夹。运行过程中：

- 目标有歧义时，它会问你，你在卡片上回答；
- 发送、删除或无法撤回的操作之前，它会先征得你的同意；
- 如果某个应用只在前台才响应，它会等你几秒钟不动鼠标键盘时再做，你也可以把电脑交给它用 5 分钟。

运行结束后，得心会显示附加的文件夹里改动了什么。
